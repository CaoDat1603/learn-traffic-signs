# Learn-Traffic-Signs-App (BIỂN BÁO VIỆT)

**BIỂN BÁO VIỆT** is an Android application built with **Java** to help users learn, look up, and practice traffic signs in Vietnam. The app provides access to the latest traffic sign regulations and aims to educate and support both new and experienced drivers.
![image](https://github.com/user-attachments/assets/ed7f15c2-6244-4259-af33-485eda7fb7bd)

---

## 🚦 Features
- ✅ Learn traffic signs  
- 🔍 Look up traffic signs  
- 📝 Test your knowledge of traffic signs  

---

## ⚙️ Technologies Used
- **Backend**: Java (Android)  
- **Database**: SQLite  
- **APIs**: PyTouch, YOLO  
- **Build Tool**: Gradle (Groovy)

---

## 🔍 Research Methods
- 📚 **Documentation**: Studying Java programming and Android app development  
- 🛠️ **Design & Architecture**: Using the **MVC** design pattern, database design with **SQLite**  
- 🧪 **Testing**: Evaluating functionality, performance, and user experience

## ⚡️ Installation
1. Clone or download the project:
    ```bash
    git clone https://github.com/CaoDat1603/learn-traffic-signs.git
    ```
2. Open the project in **Android Studio**.
3. Build and run the app on an emulator or Android device.
4. Alternatively, download the [`.apk` file](https://1drv.ms/f/c/594a0e6a2de7da62/Ev3Q7wZdJ-5LrmCzbyAyK3wByR8Ao-YBs0B1fUcee1pxcA) file and install it on your device.
